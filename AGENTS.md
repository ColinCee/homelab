# Agents

Checks: `mise run ci`

That runs what CI's check job runs: lint, typecheck, test and validate:compose
(Compose validation needs Docker). Run it before pushing.

Everything else lives where it already is: `README.md` for what runs here and
how to run it locally, `docs/` for architecture and runbooks, and
`.github/copilot-instructions.md` for the repo's working rules.
